# IPCheckStation · IP 检测台

Windows 和 Android 的公网 IP 检测工具。默认离线，检测历史保存在当前设备。

- [Windows 32 位和 64 位安装包](https://github.com/qianfeile-cyber/IPCheckStation/releases/tag/v1.1.0)，支持自选安装路径。
- [Android APK](https://github.com/qianfeile-cyber/IPCheckStation/releases/tag/v1.0.0)。
- [源码及离线数据库 ZIP](IPCheckStation-Source.zip)。
